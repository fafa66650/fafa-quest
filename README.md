# FAFA QUEST v0.3.0 — IMMERSIVE

Application PWA statique prête pour **GitHub Pages**.

## Déploiement
1. Décompresser le ZIP.
2. Mettre **tout le contenu** à la racine du dépôt `fafa-quest`.
3. GitHub → **Settings → Pages → Deploy from a branch → main / root**.
4. Ouvrir l’URL GitHub Pages.

## Ce que contient cette version
- 14 scénarios originaux, classés par âge, thème et format.
- 90 épreuves au total.
- 4 niveaux : Découverte, Aventure, Expert, Maître.
- Création de plusieurs équipes et répartition aléatoire des participants.
- Rôles de coopération.
- Chronomètre intégré, pause et ajout de temps.
- Tableau animateur avec progression de chaque équipe.
- Messages animateur et déblocage manuel en cas de besoin.
- Mode **Écran central / TV** pour les jeux à plusieurs salles ou mondes.
- Mode 1 appareil par équipe et mode solo/famille.
- Épreuves numériques et hybrides : ordre, mémoire, sons, codes couleur, clavier, cryptographie, calques, fouille, objets physiques, associations, rôles distribués, etc.
- PWA utilisable hors connexion après le premier chargement.

## Limite actuelle
GitHub Pages est un hébergement statique : le suivi en direct entre **plusieurs téléphones différents** n’est pas encore synchronisé par Internet. Le mode Écran central, en revanche, est prévu pour fonctionner sur un seul ordinateur relié à une TV ou un vidéoprojecteur et permet de gérer plusieurs équipes simultanément.

## Contenus
Les fichiers fournis ont servi à analyser les meilleures mécaniques et les problèmes rencontrés sur le terrain. Les scénarios intégrés ont été réécrits et restructurés pour FAFA QUEST. Les univers ou personnages protégés présents dans certaines références ne sont pas reproduits.
