# FAFA QUEST v0.5 — HYBRID / SOURCE EDITION

Application unique pour GitHub Pages, sous l'identité **FAFATRAINING • ESCAPE • IMMERSION**.

## Cette version
- 32 jeux originaux / adaptés et 204 épreuves.
- 13 jeux dans le monde **Questions d'ados**, classés par thèmes.
- Modes 100 % numérique, hybride papier/objets, équipe et écran central/TV selon le jeu.
- Kit imprimable intégré pour les principaux jeux hybrides : fiches animateur, cartes équipes et supports de jeu originaux à imprimer.
- 4 niveaux : Découverte, Aventure, Expert, Maître.
- Mode animateur protégé, rotation des équipes, terminal central, écran public, mode test, PWA/offline.

## Déploiement GitHub Pages
Déposer directement le contenu de ce dossier à la racine du dépôt GitHub Pages.

Les créations tierces fournies comme références sont utilisées comme **benchmark de mécaniques et de structure**. Les textes, visuels, musiques et personnages protégés ne sont pas redistribués ; les adaptations FAFA QUEST utilisent des contenus et interfaces originaux.
